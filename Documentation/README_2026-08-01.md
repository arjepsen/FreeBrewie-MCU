Notes:
- The protocol document is included here as the shared cross-system truth.
- The current protocol document date reflects the 2026-08-01 cross-document alignment
  after the valve command wire-value cleanup and SOM reset-line confirmation.
- The current pin-map document date reflects the 2026-08-01 confirmation that SOM
  A13 `PE9` / Linux `gpio137` drives the ATmega2560 reset input.
- The intended update workflow is now:
  1. build `firmware.hex` in PlatformIO
  2. copy that hex to the SOM
  3. flash from the SOM over `/dev/ttyS1`
  4. reserve USBasp/ISP for bootloader recovery/bootstrap only
- USBasp recovery uses the `mega2560_recovery_usbasp` custom target
  `Restore Bootloader USBasp`. Do not use the built-in PlatformIO `Burn Bootloader`
  target for this board.
- Hardware testing showed the final bootloader lock byte must remain open
  (`lock=0x3F`) and the high fuse must keep reset directed to the bootloader (`hfuse=0xD8`).
  Applying the stock final lock byte `0x0F` made the FreeBrewie app fail to start.
